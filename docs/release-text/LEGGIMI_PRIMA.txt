LocalOfficeAI v0.16.0 - ALPHA PORTABLE
======================================

IMPORTANTE:
- Questo e' un pacchetto alpha portable.
- Non e' ancora un installer one-click.
- Non modifica automaticamente Word, registry o firewall.

PREREQUISITI MINIMI:
1. Windows
2. Microsoft Word desktop installato
3. Node.js LTS installato e disponibile nel PATH
4. Ollama installato
5. Almeno un modello Ollama leggero disponibile
   Consigliati:
   - qwen2.5-coder:1.5b
   - qwen2.5-coder:3b

FLUSSO CONSIGLIATO:
1. Estrai completamente lo ZIP in una cartella normale.
2. Non avviare file direttamente dentro lo ZIP.
3. Apri la cartella estratta.
4. Esegui:
   01_Verifica_prerequisiti.bat
5. Se i prerequisiti sono OK, esegui:
   02_Prepara_catalogo_Word.bat
6. Segui la guida mostrata per Word.
7. Esegui:
   03_Avvia_LocalOfficeAI.bat
   oppure Start-LocalOfficeAI.bat
8. Verifica che la tray compaia vicino all'orologio di Windows.
9. Apri Word e carica l'add-in.

SE VUOI USARE POWERSHELL MANUALMENTE:
- usa sempre:
  powershell -ExecutionPolicy Bypass -File .\tools\Test-LocalOfficeAI-Prerequisites.ps1
- non usare direttamente:
  .\tools\Test-LocalOfficeAI-Prerequisites.ps1

SE QUALCOSA NON PARTE:
- Controlla:
  docs\TROUBLESHOOTING_WINDOWS.md
- Controlla i log dalla tray app
- Verifica che Ollama sia avviato
- Verifica che Node.js e npm siano installati

GUIDE DETTAGLIATE:
- docs\INSTALL_WINDOWS.md
- docs\WORD_SIDELOAD_WINDOWS.md
- docs\FIRST_RUN_CHECKLIST.md
- docs\TROUBLESHOOTING_WINDOWS.md

NOTA:
Il documento Word non viene modificato direttamente.
Il flusso resta:
anteprima -> copia negli appunti -> incolla manuale

SESSIONE ASSISTITA:
- La nuova modalita' Sessione assistita usa uno snapshot del testo selezionato.
- Dopo avere letto la selezione, puoi avviare una sessione e fare richieste successive sullo stesso testo.
- Le risposte della sessione vanno copiate manualmente, come le anteprime.
- La cronologia della sessione resta solo in memoria nel task pane e puo' andare persa ricaricandolo.
