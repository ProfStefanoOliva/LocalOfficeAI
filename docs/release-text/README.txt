LocalOfficeAI - README rapido per pacchetto portable
====================================================

1. Apri prima:
   LEGGIMI_PRIMA.txt

2. Verifica i prerequisiti:
   tools\Test-LocalOfficeAI-Prerequisites.ps1

3. Avvia LocalOfficeAI:
   Start-LocalOfficeAI.bat

4. Prepara il catalogo Word:
   tools\Prepare-WordSideloadCatalog.ps1

5. Segui la guida completa:
   docs\WORD_SIDELOAD_WINDOWS.md

6. Primo test suggerito:
   - avvia Ollama
   - avvia la tray
   - apri Word
   - leggi una selezione breve
   - genera anteprima
   - copia negli appunti
   - incolla manualmente

Se vedi errori:
- docs\TROUBLESHOOTING_WINDOWS.md
- docs\INSTALL_WINDOWS.md
- docs\FIRST_RUN_CHECKLIST.md
